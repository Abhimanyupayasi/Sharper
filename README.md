

# Welcome to Sharper 🧠

**Sharper** is your personal AI-powered memory assistant.

Organize your daily tasks, notes, ideas, and learning materials in one place.  
Create date-wise notes, manage tasks, and structure your knowledge with categories and chapters.  
Use AI to find information, summarize notes, and get answers from your saved knowledge.  
Access your information whenever you need it, even offline.  
Built with React Native, Expo, TypeScript, and SQLite.

**Never forget. Always stay sharper.**
